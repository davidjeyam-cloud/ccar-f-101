The first 🔑 page is 1.1 (Day 1). Cheapest current model: Claude Haiku 4.5 ($1 in / $5 out per million tokens, checked 2026-09-21). Prices change — recheck before buying.

## Baseline shortcut
If the Day 0 baseline shows a domain at **80% or better**, skip that domain's "concept + build" pages and keep only its quiz and its capstone.

## Capstone shrinking rule
If time is short, shrink **06e** and **06f** first (design + break tests only). **Never** cut the break tests of **06a** and **06b**.
